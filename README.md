# MarketList — site

Página de apresentação do MarketList, a partir do layout no Figma.

## Rodar

```bash
cd /Users/thiagolourenco/Develop/IOS/website
npm install
npm run dev
```

Abre em [http://localhost:3000](http://localhost:3000).

## App Store

O botão “Baixar na App Store” usa `NEXT_PUBLIC_APP_STORE_URL`. Defina a URL da loja nesse ambiente quando o app estiver publicado.
